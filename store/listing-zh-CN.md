# Chrome 应用商店资料 — 简体中文

## 产品信息

**名称：** Zero Tab

**简短说明：**  
将新标签页变成开发者工作台：整理标签、清理重复项、稍后阅读，并关注 AI Builder 最新动态。

**分类：** 效率工具

**语言：** 简体中文

## 详细介绍

Zero Tab 将 Chrome 新标签页变成专注、克制的开发者工作台。

所有打开的标签页会按照域名自动分组。你可以跨窗口跳转到已有标签，准确关闭指定页面，保护置顶标签，并一键清理所有重复标签。

### 管理标签页

- 自动按照域名分组
- 将 Gmail、GitHub、YouTube 等首页放入独立分组
- 关闭单个标签、整个域名分组或所有非置顶标签
- 一键关闭所有重复标签
- 自动保护置顶标签
- 显示 localhost 端口，便于区分本地开发项目

### Saved for later

关闭页面前，可以先将其保存到稍后阅读清单。完成的条目会进入可搜索的归档。所有数据仅保存在本机 Chrome 扩展存储中。

### 可选的 AI Builder Daily Report

用户主动启用后，可以按时间查看 AI Builder、工程博客和播客的公开动态。该功能默认关闭，仅在启用时申请读取 GitHub 上公开 JSON Feed 的权限。

你可以点击原文、标记已阅读，并在 Chrome 支持时使用浏览器内置 Translator API 进行本地翻译。

### 本地优先

Zero Tab 没有发布者运营的服务器、账号系统、广告或分析追踪。标签页 URL、标题、保存链接、偏好和阅读状态都留在本机。

AI Builder Daily Report 不会上传浏览数据；请求中不包含标签页信息、用户标识、凭据或 API Key。
