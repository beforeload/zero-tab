Zero Tab is a local-first Chrome extension that replaces the new tab page with a dashboard for organizing open tabs.

Data Zero Tab handles

Zero Tab processes open-tab URLs, titles, favicons, window identifiers, pinned state, and active state locally in the browser. It also handles links saved for later, preferences, read states, translations, and cached public-feed content.

Local storage

Saved links, preferences, AI Builder Daily Report cache, read state, and translations are stored in chrome.storage.local. Zero Tab does not operate a server and does not synchronize this data to the publisher.

AI Builder Daily Report

This optional feature is disabled until the user enables it. When enabled, Zero Tab downloads public JSON feeds from https://raw.githubusercontent.com/. These requests do not contain tab data, saved links, browsing history, identifiers, credentials, or API keys.

On-device translation

When supported and explicitly requested, Zero Tab uses Chrome's built-in Translator API. Chrome may download a language pack or model. Zero Tab does not send report text to a third-party translation API.

Sharing and sale

Zero Tab does not sell, rent, transfer, or share user data with advertisers, data brokers, analytics providers, or the publisher. It does not use Chrome API data for advertising, credit decisions, or unrelated profiling.

Security and Limited Use

  • All extension logic is packaged with the extension.
  • Optional feed requests use HTTPS.
  • Remote feed strings are rendered as untrusted data and cannot execute code.
  • Chrome API data is used only for the extension's user-facing developer workspace functionality.

User controls

Users can leave the report disabled, revoke the optional GitHub permission, remove saved content, clear extension data, or uninstall Zero Tab.

Third-party content

The report displays links and excerpts from public third-party sources. Those sources have their own terms and privacy policies.
