## Detailed description

Zero Tab turns Chrome's new tab page into a focused developer workspace.

See every open tab at a glance, grouped by domain. Jump to an existing tab across windows, close exact tabs without affecting unrelated pages, protect pinned tabs, and clear duplicates in one click.

### Keep tab overload under control

- Group tabs automatically by domain
- Keep common homepages together
- Close one tab, one domain, or every unpinned tab
- Remove duplicate tabs globally
- Preserve pinned tabs
- See localhost ports for local development projects

### Save useful links for later

Move a tab into a local Saved for later checklist before closing it. Completed items move into a searchable archive. Saved links remain in Chrome extension storage on your device.

### Optional AI Builder Daily Report

Enable a chronological feed of public updates from selected AI builders, engineering blogs, and podcasts. The report is disabled by default and requests access only to public JSON files on GitHub when enabled.

Cards can be marked as read, opened at their original source, and translated with Chrome's on-device Translator API when supported.

### Local-first by design

Zero Tab has no publisher-operated server, account system, advertising, or analytics. Open-tab URLs, titles, saved links, preferences, and read state stay on the device.

AI Builder Daily Report never uploads browsing data. Its optional requests contain no tab information, identifiers, credentials, or API keys.
